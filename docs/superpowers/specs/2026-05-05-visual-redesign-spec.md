# Synapse Daily 视觉重设计规格

## 概述

基于 frontend-design 技能对 GitHub Pages 日报页面进行系统性视觉升级。保留领奖台+列表结构，采用"金棕典雅"美学方向，通过评分分层、悬浮动效和精致的排版细节提升视觉冲击力。

## 美学方向：金棕典雅

- **调性**：编辑级技术情报简报 — 有温度的权威感
- **核心对比**：象牙白底色 × 深棕文字 × 暖金点缀
- **零外部依赖**：全部使用系统字体，国内直连友好

## 评分三档分层

**原则：文字始终 #2d1b0e，可读性不妥协。区分度通过装饰元素实现。**

| 元素 | 🥇 9-10 分 | 🥈 7-8 分 | 🥉 ≤6 分 |
|---|---|---|---|
| **左侧色条** | 金色 3px `#daa520` | 灰棕 2px `#c8bfb0` | 无 |
| **卡片底色** | 暖金淡底 `rgba(218,165,32,0.06)` | 纯白 `#fff` | 纯白 `#fff` |
| **评分徽章** | 实心金圆 `bg:#daa520` `color:#fff` | 浅金描边圆 `bg:#f5ede0` `border:#e0d4c0` | 灰描边圆 `bg:#f5f0e8` `border:#e0dcd5` |
| **标题字重** | 600 | 600 | 600 |
| **标题颜色** | `#2d1b0e` | `#2d1b0e` | `#2d1b0e` |
| **标签颜色** | 正常彩色 | 正常彩色 | 暖灰系 |
| **排名编码** | `font-weight:600` `color:#b8860b` | `font-weight:400` `color:#999` | `font-weight:400` `color:#999` |

## 悬浮动效

### 领奖台卡片

- **Normal**：白底 + 微阴影 `0 2px 8px rgba(0,0,0,0.04)` + 默认边框 + 对应金属色顶边
- **Hover**：上浮 4px + 放大 2% + 金属色强阴影（金 `rgba(184,134,11,0.18)` / 灰 `rgba(0,0,0,0.1)` / 铜 `rgba(205,127,50,0.14)`）+ 金色边框 + 标题变金 + 顶部渐变亮条
- **Transition**：`all 0.25s ease`

### 列表卡片

- **Normal**：白底 + 微阴影 `0 1px 3px rgba(0,0,0,0.03)` + `#e8e0d5` 边框 + 对应评分分层装饰
- **Hover**：上浮 2px + 金色边框 `#daa520` + 金色阴影 `0 4px 20px rgba(0,0,0,0.08)` + 淡金渐变底色 + 标题变金 + 评分徽章放大 `scale(1.12)`
- **9-10分 hover**：更浓郁金色底色 `rgba(218,165,32,0.1)` + 金色投影 `rgba(184,134,11,0.15)`
- **Transition**：`all 0.2s ease`

## 文件变更范围

仅修改 `pages/` 目录下的文件：
- `pages/assets/css/style.scss` — 完全重写样式
- `pages/_layouts/default.html` — 更新 header 结构
- `pages/index.html` — Top 3 podium + 列表分拆逻辑
- `pages/_includes/item-card.html` — 列表卡片（含评分分层 class）
- `pages/_includes/podium-card.html` — 领奖台卡片（已有，微调）

## 不做什么

- 不引入外部字体（Google Fonts 等）
- 不改变 Jekyll 构建流程
- 不修改 `_config.yml`
- 不添加 JavaScript
- 不含暗色模式（保持单一暖色主题）
