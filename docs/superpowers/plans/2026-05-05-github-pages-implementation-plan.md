# GitHub Pages Display Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Jekyll-based static site displaying Synapse daily digest content on GitHub Pages, deployed automatically after digest generation.

**Architecture:** Jekyll site in `pages/` directory with Liquid templates rendering digest JSON as ranked cards. CI workflow copies the latest `data/digests/{date}.json` into `pages/_data/digest.json`, generates a history index, and deploys to `gh-pages` branch via `peaceiris/actions-gh-pages`.

**Tech Stack:** Jekyll (GitHub Pages native), Liquid templates, SCSS, GitHub Actions

### Task 2: CI/CD — deploy-pages.yml

**Files:**
- Create: `.github/workflows/deploy-pages.yml`

- [ ] **Step 1: Create `.github/workflows/deploy-pages.yml`**

```yaml
name: Deploy to GitHub Pages

on:
  workflow_dispatch:
  workflow_call:

permissions:
  contents: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Get digest date
        id: date
        run: echo "date=$(date +%Y-%m-%d)" >> $GITHUB_OUTPUT

      - name: Prepare data files
        run: |
          DIGEST_DATE="${{ steps.date.outputs.date }}"
          DIGEST_FILE="data/digests/${DIGEST_DATE}.json"

          if [ ! -f "$DIGEST_FILE" ]; then
            echo "::error::Digest file not found: $DIGEST_FILE"
            exit 1
          fi

          mkdir -p pages/_data
          cp "$DIGEST_FILE" pages/_data/digest.json

          # Generate history.json from available digest files
          ls data/digests/*.json | sed 's|data/digests/||;s|\.json||' | sort -r | jq -R -s -c 'split("\n") | map(select(length > 0) | {date: .})' > pages/_data/history.json

          echo "Deploying digest for ${DIGEST_DATE}"
          cat pages/_data/history.json

      - name: Deploy to gh-pages
        uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./pages
          publish_branch: gh-pages
          force_orphan: true
```

### Task 3: Integrate deploy-pages into daily-digest.yml

**Files:**

- [ ] **Step 1: Add deploy-pages job to daily-digest.yml**

Add the following at the end of the `jobs:` block (after the `digest` job):


The full file after modification:

```yaml
name: Daily Digest

on:
  schedule:
    - cron: "0 8 * * *"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  digest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: "10.0.x"

      - name: Generate and deliver digest
        env:
          OpenAI__ApiKey: ${{ secrets.OpenAI__ApiKey }}
          OpenAI__BaseUrl: ${{ secrets.OpenAI__BaseUrl }}
          OpenAI__Model: ${{ secrets.OpenAI__Model }}
          WeCom__WebhookUrl: ${{ secrets.WeCom__WebhookUrl }}
        run: dotnet run --project src/Synapse.Cli -- generate-digest

      - name: Archive digest
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add data/
          git diff --staged --quiet || git commit -m "chore: archive daily digest $(date +%F)"
          git push

  deploy-pages:
    needs: digest
    uses: ./.github/workflows/deploy-pages.yml
    permissions:
      contents: write
```
